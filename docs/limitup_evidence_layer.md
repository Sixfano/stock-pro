# 连板证据层升级说明

## 目的

本次升级只服务于每日连板筛选的“论述依据、复核和风险提示”，不改变现有四套核心策略：

- 一进二
- 二进三
- 三进四
- 高标接力

新增数据默认进入 `evidence/shadow` 层，不自动修改基础策略分数。

## 新增证据

1. **个股资金流**
   - 主力净流入占比
   - 超大单/大单净流入
   - 用途：判断涨停后是否存在资金确认，或是否属于高换手分歧。

2. **板块资金流**
   - 概念/行业主力净流入
   - 板块资金排名
   - 用途：确认个股是否与题材共振，避免只看单票封板。

3. **龙虎榜**
   - 龙虎榜净买额
   - 净买额占总成交比
   - 上榜原因
   - 用途：解释筹码交换、席位承接和次日潜在兑现压力。

4. **强势股池/涨停基因**
   - 近期多次涨停
   - 60日新高
   - 量比
   - 用途：补强“涨停基因、辨识度、启动结构”的论述。

5. **量价结构**
   - 均价线承接
   - 量比
   - 收盘位置
   - ATR/波动率
   - 用途：只作为换手接力是否健康的辅助证据。

6. **筹码代理**
   - 换手率
   - 成交额相对5日均值
   - 上影/收盘位置
   - 用途：在完整 CYQ 成本分布接入前提供代理信号。
   - 注意：代理不能替代真实筹码分布。

## 明确不做的事

- 不把 MACD/KDJ/RSI 变成连板核心触发条件。
- 不把资金净流入简单等价为“可以买”。
- 不因为一字板强就提高可交易性评分。
- 不因为封板早就机械提高排名。
- 不改变四套策略原有基础权重。
- 不直接自动下单。

## 后续可进一步接入

- 完整 CYQ 成本分布：成本峰、获利盘、90%/70%筹码集中度。
- 竞价逐笔：撤单、撮合金额变化、同身位竞价卡位。
- 板块高标反馈：高位核心的溢价、断板、负反馈和回流。
- 题材竞争矩阵：主线、次主线、日内卡位、回流概率。
- 数据源容灾：AKShare → 直接东财/同花顺 → OpenTDX/其他备用源。


## V2：四个高价值连板证据模块

### 1. 真实 CYQ 筹码成本分布

数据源优先使用 `stock_cyq_em`，记录：

- 获利比例
- 平均成本
- 90% 成本低/高
- 90% 集中度
- 70% 成本低/高
- 70% 集中度

使用目的：

- 判断高换手后筹码是否真正完成交换；
- 判断上方套牢成本区是否已经消化；
- 判断现价是否远离平均成本、形成过高浮盈兑现压力。

明确约束：CYQ 只确认“换手接力质量”，不单独触发买入。

### 2. 板块高标反馈矩阵

对题材中前一交易日的高标/核心股记录：

- 身位
- 次日竞价
- 当日涨跌幅
- 是否封板/跌停
- 均价线承接
- 是否板块核心

高标负反馈具有非对称影响：核心高标接近跌停或持续均价线下运行时，
即使低位票自身封板漂亮，也要降低对该题材接力持续性的信任。

### 3. 同身位卡位关系

只在“已经进入对应接力候选池”的股票之间比较：

- 竞价强度
- 换手质量
- 涨停质量
- 板块强度
- 龙头辨识度
- 可交易性

同一题材、同一身位存在多只候选时，默认保留主动性更强、带动性更好的个股，
避免日报候选过度重复。

### 4. 题材回流倾向分

输入：

- 前期题材热度/辨识度
- 上一阶段分歧释放程度
- 板块资金回流
- 高标反馈
- 梯队完整度
- 板块广度恢复
- 次日核心竞价（可选）

输出 0-100 的“回流倾向分”。

注意：它目前不是经过统计校准的真实概率，因此报告中必须称为
“回流倾向/回流条件”，不能写成“80%概率回流”。待积累足够历史样本后，
再用实际回流标签做概率校准。

## 各身位使用侧重

- 一进二：同身位卡位 > CYQ/换手 > 板块资金 > 题材回流。
- 二进三：高标反馈 + 同身位卡位 + CYQ + 板块梯队。
- 三进四：高标反馈权重在论述中进一步提高，重点防题材退潮时的中高位补跌。
- 高标接力：高标自身反馈、题材回流条件、市场高度与情绪周期优先，CYQ用于兑现风险解释。

这些是“论述优先级”，不是对原四套策略基础权重的重写。

# A-Stock Limit-Up Engine

可复用的 A 股连板接力研究与选股框架。

目标：将市场数据、涨停/连板结构、板块梯队、竞价强度、市场情绪、量化因子、风险过滤和四套独立接力策略整合为可运行、可回测、可扩展的研究项目。

四套策略：
- 一进二
- 二进三
- 三进四
- 高标接力

原则：
- 数据 provider 与策略解耦
- 所有因子 point-in-time
- 严格防未来函数
- 默认只研究和输出候选池，不自动下单
- 初始权重只是研究参数，必须通过历史回测验证

## 2026-08-17 收盘复盘后的护栏升级

本次更新不调整四套策略的基础权重，只加入可立即验证的筛选护栏和影子因子：

- 09:35 输出正式池，10:00 仅复核前一日有辨识度且板块梯队仍完整的延迟弱转强候选。
- 将 0% 至 +5% 的竞价涨幅保留为软特征，不再作为单一硬阈值。
- 开板次数改为非线性分歧质量，结合最终封板、封单比例、均价承接和回封时长。
- 一字板的强度与可交易性分开评分。
- 情绪状态只生成影子乘数；修复期提高回封容忍，退潮期提高高位门槛。
- 同时记录精度、召回率、假阴性和可交易成功率。

至少累计 5 至 10 个交易日、50 至 100 个候选后，才评估是否重估核心权重。

## 2026-08-19 连板证据层升级

本次升级继续保持四套策略的基础权重不变，新增内容默认只作为每日连板筛选的论述依据和影子证据：

- 个股资金流：主力、超大单、大单净流入。
- 板块资金流：行业/概念资金共振与排名。
- 龙虎榜：净买额、净买占比、上榜原因。
- 强势股池：近期多次涨停、60日新高、量比等涨停基因。
- 量价结构：均价线承接、成交扩张、收盘位置和波动。
- 筹码代理：换手、成交额扩张、上影和收盘位置；完整 CYQ 接入前只作代理。
- 数据源路由：允许后续接入直接东财、同花顺、OpenTDX 或 InStock 兼容 provider 做容灾。

核心约束：
- `evidence/shadow` 不覆盖策略基础分。
- 资金流和技术指标不能单独触发入选。
- 仍以连板身位、换手质量、板块梯队、龙头带动、情绪周期和竞价预期为主。
- 只有经过足够样本回测验证的证据，才允许进入正式权重。

运行当日涨停证据快照：

```bash
python scripts/run_screen.py --date 20260819
```

保存为 CSV：

```bash
python scripts/run_screen.py --date 20260819 --output reports/20260819_evidence.csv
```

详见 `docs/limitup_evidence_layer.md`。


## 2026-08-19 V2：真实筹码与题材博弈证据

继续保持四套接力策略基础权重不变，新增：

- AKShare provider 增加 CYQ、概念板历史/成份股、行业板历史接口。
- `run_screen.py` 对高优先候选追加真实 CYQ 论据。

核心交易风格仍然是：连板身位 + 健康换手 + 板块梯队 + 龙头带动 +
情绪周期 + 竞价预期。传统技术指标与新增数据只用于确认、反证和风险解释。
